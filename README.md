<h2>科学导航</h2>
</div>

### 一、产品概述

- 一个面向信息检索的科学导航站，收录常用科学检索网站、学术工具与权威检查网站。
- 内置 AI 提示词板块，勾选角色和规则即可拼出可直接使用的提示词。
- 内容力求真实、有效、有实际意义，持续更新中。

核心价值：把散落各处的检索入口收进一页，找资料先过一遍导航，少踩镜像站和假期刊的坑。

### 二、功能说明

#### 工具索引

- 收录科学信息检索网站、学术工具、权威检查网站等常用入口。
- 首页支持按标签和名称分类筛选，点搜索即开始搜索。
- 首次访问需加载内容索引，等几秒，之后秒开。

#### AI 提示词

- 勾选式生成：选一个角色、多条规则，下方自动生成提示词。
- 复制生成的提示词，填入自己的问题即可使用。

### 三、安装与下载

在线使用（官方地址）：https://science.mutantcat.org/

也从 [Releases](https://github.com/Mutantcat-Working-Group/ScienceNavigation/releases) 下载 `sciencenavigation-1.0.20260920.tar.gz` 自行静态托管部署，另附 `checksums.txt`、`checksums-md5.txt`、`checksums-sha1.txt` 供校验。版本号使用纯日期递增（如 `1.0.20260920`），推送同族标签（`v` 前缀可选）后，GitHub Actions 会自动打包并发布 Release。

### 四、快速上手

1. 打开官方地址，等索引加载完成进入首页。
2. 用标签或名称筛选想要的方向，点搜索按钮出结果。
3. 切到 AI 提示词页，勾选角色与规则，复制生成的提示词。
4. 把提示词粘贴到任意 AI 助手，补上自己的问题直接开问。
